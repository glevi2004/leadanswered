# Ramp plan (week-by-week)

Don't try to do everything at full volume from day 1. You'll do both poorly.

## Week 1 — setup, zero outreach
- Dialer + lead list infrastructure
- Build the demo (already done — see `platform/`)
- Fix LinkedIn profile (see `04-linkedin-profile.md`)
- **Goal:** ready to call by Friday
- **Calls: 0**

## Weeks 2–3 — calls only
- 60–80 calls/day to start; 100 by end of week 3
- Focus on pitch refinement, not volume
- Record everything legally allowed
- **Total: ~600 calls over two weeks**

## Weeks 4–6 — calls + LinkedIn video
- 100 calls/day + 5–8 videos/day
- Start the 4-touch sequence properly (see `06-multi-touch-sequence.md`)
- **Total: ~2,000 calls + ~100 videos**

## Week 7+ — steady state + content
- Same call + video cadence
- Add public LinkedIn content: 2 short posts/week, drawing on the outreach experience
- Start thinking about a referral system for existing pilot clients
- Begin tracking inbound (near-zero for a while, then it isn't)

## What success looks like by end of week 8

- 1–2 paying clients
- A pitch that no longer needs notes
- LinkedIn profile + 4–6 posts that look like a real founder, not a bot
- A working sense of which vertical is responding best — even if not formally niched yet
