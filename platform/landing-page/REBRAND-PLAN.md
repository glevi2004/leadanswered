## Product truths (don't violate these in any copy)

- **Built _with_ partners** on a shared foundation — never bespoke, custom-per-customer software.
- **There's an app.** We set it up for them (they can still change things). Texting Sarah
  complements it. Say "we set it up for you," never "no app."
- **Word choice:** say **"app,"** not "dashboard."
- **Scope is broad and open:** getting found (website, SEO, blog posts, social), winning work
  (leads, quotes, scheduling), getting paid & growing (invoicing, reviews, follow-ups) — **and
  more, as we build it with them.** Lists always stay open-ended, never a fixed menu.
- **Say it plainly.** The true thing, then stop. No clever qualifiers, no over-writing.
